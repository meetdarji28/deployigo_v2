🗄️ Database Manager

      

      
    

    

    

      
Connected databaseDetails available

      

      

      

      
Managed databases use an internal Docker network. Remote access is OFF. An outside computer cannot connect to the internal hostname. Remote access requires an explicit network/security feature not yet available.

      

      
Database browser (read-only, 50 rows max)

      
Select a table to preview data, similar to phpMyAdmin / pgAdmin. MongoDB browsing is not yet supported.

      

      

      

      
SQL backup and restore (prototype limits)

      

      
SQL export limited to 4 MB and import to 1 MB. Import executes SQL against your selected managed database and can overwrite records. Make a backup before importing. This is not yet a full phpMyAdmin/pgAdmin replacement.
